# 🌐 Micrositio personal – Facundo Castillo

Este proyecto es un **micrositio personal** desarrollado como proyecto académico para la materia Diseño Web 3 (Universidad ORT Uruguay).  
Su objetivo es presentar mi perfil como **desarrollador front-end**, mostrando una identidad profesional y una estructura técnica real.

El sitio está construido con **HTML, Tailwind CSS y JavaScript**, e integra herramientas como **Netlify** (hosting), **Formspree** (formularios) y **Google Tag Manager + Analytics** para el seguimiento de datos.

🧭 **Objetivo:** servir como carta de presentación orientada al trabajo freelance.  
💡 **Enfoque:** performance, diseño limpio y estructura escalable.

🔗 [Visitar el sitio](https://facundocastillo.netlify.app)
